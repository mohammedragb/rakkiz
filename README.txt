ركّز - تطبيق ويب تقدمي (PWA)

الملفات:
  index.html            التطبيق كله
  manifest.webmanifest  بيانات التثبيت (الاسم، الأيقونات، الألوان)
  sw.js                 يخزّن الملفات ليعمل التطبيق بدون إنترنت
  icons/                الأيقونات

مهم: يجب رفع المجلد على استضافة HTTPS (مثل Netlify أو Cloudflare Pages أو GitHub Pages)،
فالتثبيت وعمل الوضع بدون إنترنت لا يعملان عند فتح الملف مباشرة من الجهاز.
